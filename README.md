# ⏱ Stopwatch Web Application

## 📌 Task Description
Create an interactive and user-friendly stopwatch web application.

The application includes:
- Start, Pause, Reset functionality
- Lap time tracking and display

---

## 🚀 Features
✔ Start the stopwatch  
✔ Pause the stopwatch  
✔ Reset time to zero  
✔ Record lap times  
✔ Simple and responsive UI  

---

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript

## ⚡ How It Works

### ▶ Start
Begins counting time

### ⏸ Pause
Stops time without resetting

### 🔄 Reset
Resets timer and clears laps

### 🏁 Lap
Stores current time as lap

## ▶️ How to Run
1. Download or clone repository
2. Open `index.html` in browser

A functional stopwatch web application with lap tracking.
